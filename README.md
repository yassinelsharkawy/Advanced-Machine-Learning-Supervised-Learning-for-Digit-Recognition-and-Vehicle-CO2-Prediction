# Advanced-Machine-Learning-Supervised-Learning-for-Digit-Recognition-and-Vehicle-CO2-Prediction

An Advanced Machine Learning course project applying supervised learning to two tasks: handwritten-digit classification with MNIST using decision trees and artificial neural networks, and vehicle CO2-emission prediction using support vector machines. The repository includes Jupyter notebooks, Python GUI files, and the dataset used for regression.

This repository contains a project completed for an **Advanced Machine Learning** course at university. It explores two core supervised-learning problems through practical implementations in Jupyter notebooks:

- **Classification:** handwritten-digit recognition using the MNIST dataset, with decision-tree and artificial neural network approaches.
- **Regression:** vehicle CO2-emission prediction using a support vector machine (SVM) and the CO2 Emissions Canada dataset.

The project reflects hands-on work with different machine-learning paradigms, from image-based classification to prediction on structured environmental data. The notebooks document the project implementations, while the accompanying Python GUI files provide interfaces for the related exercises.

## Project Structure

### Decision Tree and Artificial Neural Network

- `mnist_DecisionTree.ipynb` - MNIST handwritten-digit classification with a decision tree.
- `handwritten-digit-recognition.ipynb` - handwritten-digit recognition with an artificial neural network.
- `GUI.py` - Python GUI file for the classification work.

### Support Vector Machine

- `CO2_Emission1_SVM.ipynb` - vehicle CO2-emission prediction using an SVM.
- `GUI.py` - Python GUI file for the regression work.

## Datasets

### Classification Dataset

The classification notebooks use the **MNIST dataset of handwritten digits**.

### Regression Dataset

The regression notebook uses the **CO2 Emission Prediction dataset** for vehicles. The dataset is available from [Kaggle](https://www.kaggle.com/datasets/debajyotipodder/co2-emission-by-vehicles).

## Academic Context

This work was developed as part of an **Advanced Machine Learning** university course and is intended to demonstrate the application of supervised-learning methods to both classification and regression tasks.
